# The Art Factory Website

Static website for The Art Factory, a Mumbai-based custom nameplate and sign business.

## Current features
- Home, shop, gallery, corporate, contact and legal pages
- Responsive mobile/desktop layout
- Nameplate customizer with four style variants
- Live text preview
- Size, finish and lighting options
- Price calculation
- Browser-based shopping cart
- Remove items and calculate cart total
- WhatsApp order message generated from cart
- Direct contact and corporate quote links
